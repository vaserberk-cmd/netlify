# Как обновить сайт (GitHub + Netlify)

В папке лежат файлы для корня вашего репозитория:

```
index.html
netlify.toml
package.json
netlify/functions/proxy.mjs
```

## Шаги

1. Откройте репозиторий на GitHub. Нажмите «Add file», затем «Upload files».
2. Перетащите `index.html`, `netlify.toml` и `package.json`. Для функции создайте путь `netlify/functions/proxy.mjs`: в «Add file» выберите «Create new file», введите в имени `netlify/functions/proxy.mjs` и вставьте код. (Если такая папка уже есть, откройте файл `proxy.mjs` и нажмите значок карандаша, замените содержимое.)
3. Нажмите «Commit changes». Netlify сам пересоберёт сайт за 1–2 минуты.
4. В Netlify откройте «Site configuration», затем «Environment variables». Должны быть две переменные:
   - `GEMINI_API_KEY`: ключ с aistudio.google.com/apikey
   - `GROQ_API_KEY`: ключ с console.groq.com/keys (нужен для Whisper, Qwen 3.8 и GPT-OSS)
5. После добавления или изменения переменных откройте вкладку «Deploys», нажмите «Trigger deploy», затем «Deploy site».
6. Откройте сайт и нажмите Ctrl+F5, чтобы сбросить кэш.

## Что внутри лаборатории

Снимите галочку «Демо-режим», загрузите файл и отметьте нейросети.

- Фото: Gemini, Gemma 4, Qwen 3.8.
- Аудио и видео: Gemini, Whisper v3, Whisper v3 Turbo, Gemma 4, Qwen 3.8, GPT-OSS 120B.
- Whisper только расшифровывает речь. Для Gemma 4, Qwen 3.8 и GPT-OSS расшифровка берётся из шага 4 (её заполняет Whisper или кнопка «Расшифровать через Gemini»).

## Важные ограничения

- Netlify принимает до ≈6 МБ за один запрос. Файлы больше ≈4 МБ (аудио, видео) страница отклоняет с понятным сообщением. Для таких файлов сожмите аудио или используйте Cloudflare Worker.
- Модели Groq в статусе Preview (Qwen 3.8) могут быть сняты без предупреждения. Тогда замените название в карточке на другое и обновите список `CHAT_MODELS` в `proxy.mjs`.
- Llama 3.3 70B на Groq сейчас доступна только по Enterprise-тарифу, поэтому из лаборатории убрана.
- Оценки хранятся в Netlify Blobs (через `package.json`). Если Blobs недоступно, оценки временно лежат в памяти функции и могут пропасть при перезапуске.
